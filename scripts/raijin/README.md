# Repository documentation tools

This directory contains repository-specific documentation operations. It is not part of the public `@atls/raijin` API.

- `generate-artifacts.js` reads the checked runtime and workspace manifests, then regenerates only the derived command and package references
- `check-localization-sync.js` verifies that the authored English and Russian document pairs retain the same structural markers

Normal generation and CI are offline. Authored README and quickstart files are not generated by repository scripts.

Runtime inventory and checked-bundle verification belong to the private assembly and live in `packages/assembly/scripts/surface`.
